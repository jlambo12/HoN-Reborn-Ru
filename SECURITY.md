# Политика безопасности

Не публикуйте уязвимости, токены, логины, дампы памяти или приватные логи в открытом Issue.

Для безопасного отчёта используйте GitHub Private Vulnerability Reporting на вкладке **Security** репозитория. Если функция недоступна, откройте Issue без технических деталей и попросите владельца предоставить приватный канал связи.

Поддерживается последняя опубликованная версия локализации. Установщик изменяет только `%LOCALAPPDATA%\Juvio\extensions` и перед заменой архива создаёт резервную копию.
