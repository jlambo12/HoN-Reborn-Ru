`public/brand/hon-reborn-logo.webp` is an optimized web derivative of the original logo. `public/favicon.png` is an optimized 64×64 derivative; its original is preserved in `source-assets/hon-icon-original.png`.

`public/hero/hon-reborn-gameplay.webm` and `public/hero/hon-reborn-gameplay.mp4` are muted, optimized 1280×720 web derivatives of the official announcement trailer. The page loads them only on larger screens when reduced-motion and data-saving preferences allow video playback.
