# Руководство по русской локализации HoN Reborn

## Главный принцип

Переводим механику, а не отдельные слова. Если смысл не доказан контекстом или game data, запись получает `REVIEW — DO NOT GUESS`.

## Приоритеты

1. Точность механики.
2. Понятность новичку.
3. Единообразие терминологии.
4. Естественный русский.
5. Соответствие размеру и функции UI.
6. Буквальная близость к English только после предыдущих требований.

## Multi-source архитектура

- Текущий game source определяет смысл и актуальную механику.
- Project-approved перевод имеет высший переводческий приоритет только при
  совпадающем current source hash.
- Donor и Pass C являются кандидатами, а не утверждённой translation memory.
- Хороший русский текст не доказывает актуальность механики.
- Для items, abilities, bosses, states и systems обязателен current entity
  context и `SEMANTIC_REVIEW_REQUIRED` до ручного утверждения.

## Формулировки tooltip

- Ясно указывать причину и результат: кто активирует, на какую цель, что происходит и сколько действует.
- Не смешивать длительность эффекта, время применения, интервал и перезарядку.
- Для динамических чисел без plural rules предпочитать безопасные формы: `Длительность: {value} с`.
- Не добавлять механику, которой нет в entity data или утверждённом источнике.
- Не удалять числа, формулы, placeholders, markup, escape-последовательности и структурные переносы строк.

## Терминология

- Использовать контекстные правила из `glossary_ru.json`.
- Не применять глобальный словарь: `charge` может быть зарядом предмета, накоплением, временем подготовки или рывком.
- Избегать необязательного сленга и сокращений: `КД`, `дамаг`, `МС`, `АС`.
- Предпочитать полные формы: `Перезарядка`, `Скорость передвижения`,
  `Скорость атаки`, `Урон`, `Магический урон`, `Чистый урон`.
- Сокращение допустимо только как отдельное layout-aware решение после ревью.
- Русский UI не обязан повторять English Title Case.

## Имена сущностей и поиск

- Proper names предметов по умолчанию `KEEP_EN`.
- Ссылка на предмет должна совпадать с названием в магазине: `Staff of the Master`.
- Не использовать `Стафф`, `Посох Мастера`, `Аганим` или `Аганимский скипетр`.
- `Tier I`, `Tier II`, `Tier III`, `Tier IV` сохраняются без изменений.
- Перевод proper names и RU aliases для поиска — отдельное архитектурное решение.

## Качество русского

- Не использовать буквальные машинные конструкции.
- Соблюдать падежи, управление, пунктуацию и согласование.
- Не считать наличие кириллицы доказательством качества.
- Не сокращать механику ради layout автоматически; длинную строку помечать `LAYOUT_RISK`.

## Статусы

- `APPROVED`: утверждено и может применяться при совпадающем source hash.
- `APPROVED_CANDIDATE`: предложение прошло автоматическую проверку, но ещё не runtime-approved.
- `KEEP_EN`: защищённый оригинальный текст.
- `TECHNICAL`: внутренний или debug-текст.
- `REVIEW`, `BLOCKED_NO_CONTEXT`, `STALE`: запрещены для автоматического release patch.

## Asset text

Текст внутри PNG/JPG/texture относится к `asset_text`. Его нельзя исправлять заменой localization key без отдельного asset workflow.
