# Точечные исправления скриншотов, 2026-09-04

## Причина регрессии магазина

В beta.18 лежал старый ui/fe3/sections/store.package: отсутствовали
подключение store_listpool.lua и новые store_cache_stage_label /
store_cache_step_label, необходимые текущему магазину. Пакет также содержал
удалённый upstream элемент store_cachehack.

prepare_honplus_release.py смешивал широкий рабочий build с предыдущим
релизом. Теперь принимается только архив, чей SHA совпадает с успешным
human_current_rebase.json; отсутствующие файлы не подхватываются молча.
rebase_current_release.py собирает native UI из проверенного текущего
upstream, добавляя HoN Plus отдельно, и проверяет зависимости магазина.

## Сохранение базы

build_human_release.py теперь начинает с закреплённого beta.18, а не старого
Controlled 003. Все ручные пакеты применяются поверх него. Перед следующим
переходом базы обновить BASE и EXPECTED_BASE_SHA на проверенный релиз.
Тест сравнивает все старые ключи: удаления запрещены, изменение старого
значения допускается только для ключа из ручного пакета.

## Ограничения и оставшийся визуальный проход

Игра не запускалась, локальная установка не менялась, релиз не публиковался.
Открытие магазина и отсутствие переполнения на реальном разрешении должны
быть проверены пользователем. Строку Damage в списке событий на скриншоте
нельзя считать проверенной по одному переводу общей подписи урона.

ALMOST THERE не найдено в модифицируемых строках архива. Комментарии текущего
loading.interface подтверждают, что стартовый boot screen работает до
FileManager и не читает дерево модов. Для этого экрана нужен отдельный
подтверждённый способ локализации, без самостоятельной правки бинарников.
