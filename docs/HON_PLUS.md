# HoN Plus

HoN Plus развивается как универсальный Windows-лаунчер для HoN Reborn. Текущий
русификатор остаётся первым встроенным модулем и сохраняет совместимость с уже
установленными версиями HoN Reborn RU.

## Первый рабочий срез

- единый каталог модулей со стабильными идентификаторами;
- общий контракт проверки, установки и удаления модуля;
- встроенный модуль `ru-localization` поверх проверенного `InstallService`;
- прежние пути данных, резервные копии и формат `install-state.json`;
- прежний формат GitHub Release manifest на время перехода.

Интерфейс пока показывает один модуль. Следующий этап — отдельный экран модулей
и обобщённый release manifest, в котором каждый модуль имеет собственную версию,
архив, SHA-256, размер и ограничения совместимости с игрой.

## Экспериментальная статистика в игре

В послематчевом экране доступна вкладка `HoN Plus`. Она обращается только к
локальному read-only API на `127.0.0.1:17821` и показывает три percentile-оси
для одинаковых `HeroId + RoleIndex + TimeBucket`: Economy, Combat и Team Impact.
Числовые роли отображаются без выдуманных названий, пока семантика `RoleIndex`
из Juvio API не подтверждена. Для локальной проверки используются:

```powershell
.\scripts\install_honplus_test.ps1
.\scripts\run_honplus_test.ps1
```

Установщик проверяет SHA-256 текущего игрового архива, ZIP CRC, создаёт резервную
копию расширения и отказывается работать при запущенном Juvio. Скрипт запуска
поднимает API из `C:\HoN-Plus-Stats`, проверяет `/health` и только затем запускает
игру. Если открытого матча нет в Dataset v1, вкладка предлагает тестовый матч
`869842`.

## Правила модулей

1. Модуль имеет постоянный `id`, отображаемое имя и описание.
2. Проверка состояния не изменяет файлы пользователя.
3. Установка проверяет совместимость, размер и SHA-256 до замены файлов.
4. Удаление восстанавливает предыдущие файлы и отказывается удалять изменённые
   пользователем данные.
5. Модули не читают и не сохраняют данные игрового аккаунта.

## Совместимость

Переименование пользовательского интерфейса в HoN Plus не меняет имена
исполняемых файлов, каталог `%LOCALAPPDATA%\\HoN-Reborn-RU`, ярлыки и состояние
установки. Их миграция должна выполняться отдельно, атомарно и с возможностью
отката.
