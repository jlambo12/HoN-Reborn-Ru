# HoN Reborn RU v0.1.0-beta.11

Хотфикс Launcher `1.0.10`, исправляющий обнаружение новых beta-релизов.

## Launcher

- релизы теперь сортируются по semantic version, а не по порядку ответа GitHub API;
- `beta.10` и последующие версии корректно считаются новее `beta.9`;
- сохранены перенос `login.cfg`, игровые настройки, резервное копирование и безопасный откат из beta.10.

## Перевод

- используется проверенный архив перевода beta.10 без изменений;
- сохранены пять совместимых таблиц для старых UI-путей;
- устаревшие пакеты интерфейса, ломающие текущие экраны Juvio, не возвращены.

## Проверки

- добавлен регрессионный тест semantic-version сортировки релизов;
- Launcher и Updater собраны автономно для Windows x64;
- архив, SHA-256, update manifest и self-test проверяются перед публикацией.
