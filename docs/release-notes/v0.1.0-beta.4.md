# HoN Reborn RU v0.1.0-beta.4

Исправляющий beta-релиз Launcher `1.0.3`.

## Исправлено

- лаунчер автоматически разделяет склеенные команды `host_locale` и `host_maxFPS`, оставшиеся после ранней beta-версии;
- при изменении `startup.cfg` сохраняется его исходная кодировка, включая UTF-16 LE основной игры;
- основная игра запускается со своей исходной локалью, а `ru` применяется только к модулю `extensions`;
- добавлена новая тематическая иконка для Launcher, Updater, установщика и создаваемых ярлыков;
- установка и восстановление по-прежнему блокируются при запущенном `juvio.exe`.

## Как проверить автообновление

1. Откройте установленный Launcher и выберите канал «Бета».
2. Нажмите «Проверить» и согласитесь на обновление Launcher до `1.0.3`.
3. Полностью закройте HoN Reborn.
4. Нажмите «Установить / обновить» для версии `0.1.0-beta.4` — на этом шаге повреждённые конфиги будут восстановлены.
5. Запустите GearUP, а затем HoN Reborn внутри GearUP.
