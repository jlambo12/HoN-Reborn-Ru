# HoN Reborn RU v0.1.0-beta.2

Исправляющий beta-релиз автономного русскоязычного Launcher для Windows x64.

## Исправлено после beta.1

- изменение `host_locale` больше не поглощает перевод строки и не склеивает соседнюю настройку `startup.cfg`;
- добавлен регрессионный тест, запрещающий повторное появление этой ошибки;
- версия Launcher повышена до `1.0.1`, поэтому установленная beta.1 предложит автономное обновление через GitHub Releases.

## В составе

- автономные `HoNRebornRU.exe` и `HoNRebornRU.Updater.exe`, не требующие установленного .NET;
- `HoNRebornRU-Setup.exe` для установки в Windows x64;
- русификатор с проверкой совместимости игры, размера и SHA-256;
- резервная копия существующего extension и безопасное восстановление;
- запуск официальным ярлыком, через GearUP или напрямую через Juvio.

Перевод не изменился относительно beta.1: SHA-256 `99c562d00cc8c150f1354641c832cb854f1aa9632f48d7948db2bed2440b0830`.

Это beta-версия: полная визуальная проверка всех экранов после авторизации и матчевых сценариев продолжается.
