# HoN Reborn RU v0.1.0-beta.3

Исправляющий beta-релиз Launcher `1.0.2`.

## Исправлено

- основная игра сохраняет исходную локаль при старте, поэтому штатные font maps загружаются до активации русской локали модуля `extensions`;
- из прямого запуска удалён ранний параметр `-host_locale ru`, вызывавший пустой интерфейс и `Failed to acquire font`;
- установка и восстановление перевода блокируются, пока работает `juvio.exe`, чтобы исключить повреждение открытых файлов;
- обновление с beta.2 восстанавливает исходную локаль основной игры и оставляет `ru` только для extension.

## Как проверить обновление

1. Откройте установленный Launcher beta.2 и нажмите «Проверить».
2. Согласитесь на автономное обновление Launcher до `1.0.2`.
3. Закройте HoN Reborn, если она работает.
4. Нажмите «Установить / обновить» для версии `0.1.0-beta.3`.
5. Запустите игру через GearUP.
