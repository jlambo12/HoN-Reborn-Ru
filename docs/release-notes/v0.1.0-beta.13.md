# HoN Reborn RU v0.1.0-beta.13

Точечное обновление перевода по новым скриншотам игроков. Оно сохраняет тонкий слой поверх текущей версии Juvio и не возвращает устаревшие экраны.

## Исправлено

- переведён интерфейс магазина и торговой площадки; названия товаров, обликов, героев и дикторов оставлены без изменений;
- переведены обзор профиля, история матчей, коллекции и вся вкладка Honor System;
- переведены серии убийств, доминирование, завершение серий, отключения и возвращения игроков;
- переведены подсказки нижних кнопок «Друзья», «Сообщения» и «Уведомления»;
- Launcher 1.0.11 теперь переносит самый свежий `bindings/shared.json`, где игра хранит кнопку голосового чата.

## Сохранность настроек

- при обновлении выбираются только более свежие настройки между обычным и русским профилями;
- `startup.cfg`, `game_settings_local.cfg`, `voice_config.cfg`, `bindings/shared.json` и `login.cfg` сохраняются;
- заменяемые файлы предварительно резервируются, а при ошибке выполняется откат;
- ошибочный вложенный профиль beta.9 по-прежнему используется только для восстановления более свежего `login.cfg`.

## Проверки

- SHA-256 и CRC архива проверены;
- структурные токены игровых сообщений сохранены;
- по сравнению с beta.12 изменены только две таблицы строк, Preact-профиль и три адресных файла интерфейса;
- ни один файл предыдущего русификатора не удалён;
- Launcher и Updater остаются автономными Windows x64-приложениями.
