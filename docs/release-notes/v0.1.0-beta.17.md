# HoN Reborn RU v0.1.0-beta.17

Исправляющий релиз Launcher 1.0.13. Архив перевода не изменён и полностью совпадает с beta.16.

## Исправлено

- проверка GitHub Releases больше не может выглядеть зависшей много минут: подключение ограничено 10 секундами, вся операция — 30 секундами;
- убрана дублирующая кнопка «Установить / обновить»;
- кнопка «Проверить обновления» после обнаружения новой версии сразу предлагает установить её;
- если одновременно доступна новая версия Launcher, сначала предлагается безопасное автономное обновление Launcher.

## Проверки

- Launcher и Updater собраны как автономные Windows x64-приложения;
- Launcher self-test и проверки update-manifest пройдены;
- SHA-256 неизменённого архива перевода: `cc0c3bed847aaa03142a52041cd547de7a4b79fcff411024009fd7bb3bd74c42`.
