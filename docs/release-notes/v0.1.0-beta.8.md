# HoN Reborn RU v0.1.0-beta.8

Исправляющий beta-релиз с Launcher `1.0.7` и обновлённым тонким архивом локализации.

## Главное исправление

- перевод теперь устанавливается отдельным архивом `resources_ru0.jz` в основную папку HoN Reborn;
- игра запускается без режима `-mod extensions` и использует обычный профиль `Documents\Juvio\Heroes of Newerth`;
- пользовательские настройки управления, звука, магазина и интерфейса не копируются, не обнуляются и не изменяются лаунчером;
- при обновлении с beta.7 лаунчер безопасно удаляет принадлежавший ему архив из `extensions` и восстанавливает прежнее расширение из проверенной резервной копии, если оно существовало.

## Игровой интерфейс

- удалены устаревшие донорские UI-пакеты, которые подменяли актуальные экраны Juvio;
- возвращены актуальная панель приоритета ролей, магазин, матчмейкинг и Plinko;
- роль `Solo Offlane` исправлена на `Соло-оффлейн`;
- `MISSING` заменено на `ВНЕ ОБЗОРА`;
- переведены `Эмоции`, заголовок усиления Kongor/Phoenix и основные подписи Plinko;
- сохранены только проверенные нативные переопределения, построенные из текущей версии игры.

## Launcher

- Launcher и Updater остаются полностью автономными Windows x64-приложениями;
- установка, обновление, SHA-256, резервное копирование и восстановление выполняются без Python, .NET Runtime, PowerShell, Git или архиваторов;
- для GearUP сначала нажмите «Бустить», затем запускайте игру из RU Launcher или ярлыком `HoN Reborn RU — Играть`.
