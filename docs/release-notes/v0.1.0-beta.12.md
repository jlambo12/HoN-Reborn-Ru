# HoN Reborn RU v0.1.0-beta.12

Точечное обновление перевода по скриншотам игрока. Архив собран поверх текущей версии Juvio и не возвращает устаревшие экраны интерфейса.

## Исправлено

- переведены верхнее главное меню и вкладки выбора игры;
- русский язык добавлен в список языков;
- переведены названия режимов, баланс очереди и подписи приоритета ролей;
- переведено стартовое предупреждение;
- исправлен необработанный фиолетовый ключ в описании Конгора и Феникса;
- переведены кнопки новостей, объявления витрины и подписи редкости.

## Безопасность обновления

- настройки игры и `login.cfg` сохраняются действующим Launcher 1.0.10;
- исходный архив игры не изменяется;
- по сравнению с beta.11 ни один файл русификатора не удалён;
- автоматическая проверка разрешает менять только адресные файлы этого микропатча.

## Проверки

- SHA-256 и CRC архива проверены;
- проверен точный список добавленных и изменённых файлов;
- таблицы русского языка и совместимые английские алиасы совпадают;
- Launcher и Updater остаются автономными Windows x64-приложениями.
