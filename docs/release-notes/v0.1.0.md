# HoN Reborn RU v0.1.0

Первый публичный релиз-кандидат русской локализации HoN Reborn / Juvio.

## Основное

- объединённый перевод Native UI и современного Preact-интерфейса;
- русские меню, настройки, клиентские и игровые сообщения;
- описания героев, способностей, предметов и боссов;
- локализованные новости и заметки к патчам 0.12.4 и 0.12.5;
- автономная установка без Python с резервной копией и безопасным удалением.

## Известные ограничения

Это ранняя версия. Экран главного меню после авторизации, настройки, страницы патчей, часть описаний и интерфейс матча ещё требуют полного визуального прохода. Возможны английские строки из нового серверного контента, неудачные переносы и редкие неточности.
