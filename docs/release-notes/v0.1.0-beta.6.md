# HoN Reborn RU v0.1.0-beta.6

Исправляющий beta-релиз Launcher `1.0.5`. Архив перевода не изменился.

## Изменено

- режим запуска через GearUP удалён из Launcher, потому что кнопка игры внутри GearUP запускает Juvio без параметра русского языка;
- GearUP теперь используется только для включения ускорения: сначала пользователь нажимает «Бустить», затем запускает игру ярлыком `HoN Reborn RU — Играть` или кнопкой нашего Launcher;
- в окне Launcher добавлена постоянная и однозначная подсказка по GearUP;
- старый сохранённый режим GearUP автоматически переходит на прямой русский запуск;
- Launcher по-прежнему не изменяет пользовательские `startup.cfg`.

## Правильный запуск с GearUP

1. Откройте GearUP.
2. Нажмите «Бустить» и дождитесь включения ускорения.
3. Не нажимайте кнопку запуска игры внутри GearUP.
4. Запустите `HoN Reborn RU — Играть` или нажмите «Запустить игру» в RU Launcher.

Перевод запускается с проверенными параметрами `-mod "heroes of newerth;extensions" -host_locale ru`.
