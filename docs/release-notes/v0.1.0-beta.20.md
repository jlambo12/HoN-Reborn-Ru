# HoN Reborn RU v0.1.0-beta.20

Исправляющий релиз Launcher 1.0.14. Архив перевода не изменён и полностью
совпадает с beta.19.

- Если настроенный в Windows прокси не отвечает, Launcher повторяет проверку
  GitHub Releases напрямую.
- Такое же безопасное прямое подключение используется как резервный путь при
  скачивании файлов обновления.
- Общий срок проверки остаётся ограниченным 30 секундами; зависание интерфейса
  на несколько минут не допускается.
- TLS и обязательная проверка размера и SHA-256 загруженных файлов сохранены.

Пользователям Launcher 1.0.13, у которых проверка обновлений уже не работает
из-за отключённого локального прокси, нужно один раз скачать и запустить новый
`HoNRebornRU-Setup.exe` вручную. После установки Launcher 1.0.14 последующие
проверки смогут автоматически обходить такой сбой.

В игре не проверялось: содержимое русификатора побайтно совпадает с beta.19.
