# HoN Reborn RU v0.1.0-beta.1

Первый публичный beta-релиз автономного русификатора и лаунчера HoN Reborn.

## Главное

- Автономный Windows x64 Launcher: пользователю не нужны .NET, Python, Node.js, Git, PowerShell-модули или архиваторы.
- Автоматическое обновление перевода и самого лаунчера через GitHub Releases.
- Безопасная установка `extensions/resources0.jz` с SHA-256, резервной копией и восстановлением.
- Русская локаль сохраняется для запуска через официальный ярлык Juvio.
- Отдельный режим запуска GearUP: лаунчер устанавливает перевод и открывает ускоритель, после чего игра запускается внутри GearUP.
- 106 из 106 активных героев и практически все активные предметы покрыты игровым переводом.
- Полностью переведены доступные заметки патчей 0.12.4 и 0.12.5.

## Исправления перед beta-релизом

- Переписаны машинные строки меню голосований и паузы.
- Сверены механики и отредактированы описания Kongor.
- Исправлено длинное описание Booboo/Wildsoul.
- Исправлено сообщение о переподключении на этапе выбора героев.
- Устранены повреждённые фрагменты подсказки Pegasus Boots.

## Проверка

- Архив локализации: CRC PASS.
- Автоматические тесты и структурная проверка: PASS.
- Оригинальный архив игры не изменяется.

Это beta-канал. Отдельные экраны после авторизации и редкие длинные подсказки ещё могут потребовать визуальной редакторской правки. Сообщить о проблеме можно в [GitHub Issues](https://github.com/jlambo12/HoN-Reborn-Ru/issues).
