# HoN Reborn RU v0.1.0-beta.9

Исправляющий beta-релиз с Launcher `1.0.8`.

## Исправлено

- устранена ошибка GDI+ `Rectangle ... cannot have a width or height equal to 0` и красные перечёркнутые области после сворачивания или изменения размера Launcher;
- перевод снова устанавливается в `extensions/resources0.jz` и подключается через проверенный стек модов;
- параметр `-config "Heroes of Newerth"` сохраняет основной пользовательский профиль: настройки управления, камеры, звука и магазина Launcher не изменяет;
- добавлена безопасная миграция установки beta.8: старый `resources_ru0.jz` удаляется только после проверки SHA-256, а существующий extension предварительно сохраняется;
- восстановление предыдущей версии учитывает новый формат состояния установки и возвращает пользовательские файлы из резервной копии.

## Важно

- Для GearUP сначала нажмите «Бустить», затем запускайте игру ярлыком **HoN Reborn RU — Играть** или кнопкой Launcher.
- Кнопка запуска внутри GearUP не передаёт параметры русского языка.
- Релиз прошёл автоматические проверки и выпущен по запросу тестировщика; итоговая проверка запуска на пользовательской Windows продолжается.
