# HoN Reborn RU v0.1.0-beta.21

Релиз совместимости с HoN Reborn 0.12.8 и Launcher 1.0.15.

- Русификатор пересобран для текущего игрового архива SHA-256
  `ae3d51104bc6d9b6045b4123a84a31f72b1b283b4d5c9e6e96d269f1b5132643`.
- Добавлены переводы интерфейса и заметок патчей 0.12.7 и 0.12.8, новых
  игровых строк и актуального блока новостей.
- Preact, Preact Remote и нативные UI-файлы пересобраны из текущей базы игры;
  устаревшие фрагменты предыдущей версии не переносятся вслепую.
- Launcher выбирает самый новый релиз по семантической версии и не откатывается
  к промежуточному релизу при ошибке его манифеста.
- Проверка GitHub Releases охватывает до 100 последних релизов и сохраняет
  резервный прямой путь при неработающем системном прокси.

Автоматические проверки архива, TypeScript-сборки, Launcher и упаковки пройдены.
В игре не проверено; локальная установка во время подготовки релиза не менялась.
