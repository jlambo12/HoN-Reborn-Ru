# HoN Reborn RU v0.1.0-beta.5

Исправляющий beta-релиз Launcher `1.0.4`.

## Исправлено

- все игровые режимы используют проверенную строку `-mod "heroes of newerth;extensions" -host_locale ru`;
- добавлен отдельный ярлык `HoN Reborn RU — Играть`, запускающий русскую игру сразу и без окна Launcher;
- оригинальный ярлык Juvio остаётся неизменным;
- режим GearUP стал двухшаговым: сначала открыть GearUP и нажать «Бустить», затем запустить русскую игру;
- Launcher больше не изменяет `startup.cfg` во время установки или обновления;
- некорректно сохранённый старой версией путь GearUP больше не перекрывает автоматически найденный настоящий ярлык GearUP;
- запуск через игровой ярлык блокируется с понятным сообщением, если перевод ещё не установлен.

## Проверено на реальной установке

- русский Native UI и Preact UI загружаются;
- ошибок `Failed to acquire font` нет;
- внешний запуск `juvio.exe` остаётся под активным бустом GearUP;
- SHA-256 обоих пользовательских `startup.cfg` до и после установки полностью совпадает.

## Как проверить автообновление

1. Закройте игру.
2. В Launcher выберите канал «Бета» и нажмите «Проверить».
3. Согласитесь на обновление Launcher до `1.0.4`.
4. Установите перевод `0.1.0-beta.5`.
5. Для GearUP сначала нажмите в нём «Бустить», затем используйте ярлык `HoN Reborn RU — Играть`.

Перевод не изменился: SHA-256 `99c562d00cc8c150f1354641c832cb854f1aa9632f48d7948db2bed2440b0830`.
