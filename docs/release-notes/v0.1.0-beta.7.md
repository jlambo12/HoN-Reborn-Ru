# HoN Reborn RU v0.1.0-beta.7

Beta-релиз с полностью переработанным Launcher `1.0.6`. Архив перевода не изменился.

## Новый Launcher

- главное действие теперь — крупная кнопка `ИГРАТЬ`;
- добавлен атмосферный тёмный интерфейс HoN с красными и золотыми акцентами;
- стандартные Windows-кнопки, переключатели и зелёная полоса прогресса заменены едиными игровыми компонентами;
- состояния игры, перевода и файлов собраны в отдельном блоке готовности;
- выбор официального ярлыка, прямой запуск Juvio, GearUP-подсказка, канал обновлений, восстановление, журнал и страница релизов сохранены;
- длинный путь к ярлыку скрыт из основного окна и доступен во всплывающей подсказке;
- ошибки показываются понятным текстом, а технические подробности записываются в журнал;
- после запуска игры Launcher сворачивается и блокирует повторное нажатие во время запуска.

## GearUP

Сначала откройте GearUP и нажмите «Бустить», затем запускайте игру кнопкой `ИГРАТЬ` в RU Launcher или ярлыком `HoN Reborn RU — Играть`. Кнопку запуска внутри GearUP использовать не нужно.

Launcher и Updater остаются полностью автономными Windows x64-приложениями и не требуют установленного .NET или сторонних программ.
