# HoN Reborn RU v0.1.0-beta.22

Исправление Launcher 1.0.16 для восстановления русификатора после переустановки или очистки файлов Juvio.

- Если сохранённое состояние установки существует, но управляемый файл
  `Juvio\extensions\resources0.jz` исчез, Launcher больше не останавливается с
  ошибкой «Перевод предыдущей версии не найден». Он выполняет чистую проверенную
  установку и создаёт новое корректное состояние.
- Защита от перезаписи неизвестного существующего файла сохранена.
- Неисправному системному прокси отводится не более пяти секунд, после чего
  проверка обновлений повторяется напрямую с оставшимся общим лимитом времени.
- Загрузка релизного файла также повторяется напрямую после тайм-аута прокси.
- Для неподдерживаемого нового патча HoN Launcher теперь показывает отдельное
  понятное сообщение вместо общей ошибки операции.

Русификатор идентичен beta.21 и совместим с HoN Reborn 0.12.8, SHA-256
`ae3d51104bc6d9b6045b4123a84a31f72b1b283b4d5c9e6e96d269f1b5132643`.

Автоматические проверки архива, Launcher и упаковки пройдены. В игре не
проверено; локальная установка во время подготовки релиза не менялась.
