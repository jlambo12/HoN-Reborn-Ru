# HoN Reborn RU v0.1.0-beta.18

Этот релиз добавляет экспериментальный HoN Plus и совместимость русификатора с текущей версией ресурсов HoN Reborn.

## HoN Plus

- добавлена компактная live-панель под кнопками косметики и эмоций;
- во время матча показываются экономика, импакт, командный вклад, K/D/A, крипы, добивания и уровень;
- целевые значения округляются математически до целых чисел;
- панель уменьшена и не перекрывает область быстрой покупки;
- в послематчевом окне добавлены карточки игроков с иконками и именами героев;
- игроки сортируются от максимального импакта к минимальному;
- показатели сравниваются только с подходящей выборкой по герою, роли и минуте матча.

## Совместимость

- русификатор пересобран для игрового архива `b56cb49a61adf8f5e6c4a57a19de828aae9a9cfaaabf73ee0d5ad32f88c121f4`;
- исправлена потеря проверенных переводов при повторном аудите после обновления игры;
- сборка Preact Remote больше не зависает, если upstream не содержит отдельный lock-файл;
- релиз упакован как тонкий overlay без неизменённых ресурсов игры.

## Проверки

- CRC и SHA-256 архива проверены;
- native HoN Plus, Preact и Preact Remote успешно собраны;
- пройдены автоматические тесты live HUD, каталога, Launcher и релизной упаковки.
